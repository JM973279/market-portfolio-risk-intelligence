- 작업 시작 시 미커밋 변경사항과 파일 해시를 `/tmp/mpri-final-design`에 기록했다. 기존 Portfolio 등 다른 페이지의 작업을 보존했다.

- Frozen V1, Phase 7A·7B, Stress Validation, 모델·계산, API 계약, 데이터 권리·공개 제한을 변경하지 않았다.

## 시안 재현과 비교 조정

| 시안 요소 | 구현 |
|---|---|
| 가로 탐색 | 로고, 8개 주요 메뉴, 한국어·영어. 좁은 화면은 가로 스크롤과 전체 메뉴 지원 |
| 제목·배경 | ‘글로벌 시장 위험 모니터링’, 딥네이비, 아이스블루, 은은한 그라데이션·외곽 조명 |
| 대형 시장 패널 | 미국·한국 예측 점수·MSI, 관측일·수집 기준일·검증 상태. 숫자 크기와 정렬 개선 |
| 중앙 시장 위험 지도 | 미국·한국 예측 점수 색상 띠, 별도 축의 MSI 선, 한국 확산도 6개 지표, 연결된 날짜 커서 |
| 오른쪽 상세 | 날짜 입력·관측일 이동, 실제 선택일 점수·MSI, 확산도 막대, 판정 근거·출처 펼치기 |
| 반응형 | 390px에서는 시장 패널을 세로 배치하고 상세 분석을 지도 아래로 이동 |

1440px 실제 화면을 시안과 비교하며 상단 여백, 요약 패널 크기, 지도/상세 비율, 차트 높이, 도구 위치를 수정했다. 초기 구현의 별도 기간 도구 행을 제목 옆으로 옮겼고 날짜 조절은 오른쪽에 배치했다. 지속 악화 판정과 전체 기간 탐색은 펼치기 형태로 제공하여 지도가 지나치게 길어지지 않도록 했다.

시안의 지구 장식은 이미지 복제가 아닌 단순한 벡터 구면으로 구현했다. `aria-hidden`으로 처리되며 분석값이나 시장 연결을 나타내지 않는다. 시안의 검색 아이콘은 실제 검색 기능이 연결되지 않아 추가하지 않았다.

## 데이터 정확성

기존 로더와 검증 게이트를 재사용한다. 데이터 출처는 기존 `frontend/public/data/operational-markets.json`, `global-markets.json`, `korea-monitor.json`이다. 새 외부 API나 실시간 공급자를 연결하지 않았다. 수동 갱신 스냅샷이며 라이브 데이터가 아니다.

- 최신 운영 현황: 미국 검증 보류로 점수·MSI N/A, 한국 예측 점수 40.2%·MSI 0.753. 관측일과 수집 기준일도 기존 자료에서 읽는다.
- 과거 연구와 최신 운영 현황을 이어 붙이지 않는다. 최신 점수와 선택한 과거 날짜의 점수가 다른 것은 자료 기준이 다르기 때문이다.
- 기본 선택일은 양국 예측 점수와 MSI가 모두 존재하는 최근 한국 연구 관측일이다. 현재 자료에서는 2026-09-16이다. 사용자는 다른 날짜를 직접 선택할 수 있다.
- 예측 점수는 향후 10거래일 내 시장 스트레스 위험의 예측 지표다. 현재 스트레스인 MSI와 구분한다. 점수를 발생 확률이나 국가 위험 순위로 설명하지 않는다.
- MSI는 시장별 축과 원본 날짜별 임계값을 사용한다. 서로 다른 모델의 점수를 직접 비교하는 데 한계가 있음을 명시한다.
- 예측 점수는 원본 0–1 값을 색상 강도로 표시한다. 자료가 없는 날짜는 사선으로 표시한다. 확산도는 저장된 백분위 값을 사용하며 90% 이상에만 황색을 사용한다.
- 결측값을 보간하거나 이전 관측값으로 채우지 않는다. 시안의 연속적인 히트맵과 달리 실제 결측이 보이는 것은 의도한 동작이다.
- 시안의 예시 수치·날짜·임의 지표를 복사하지 않았다. 현재 데이터에 없는 신용·유동성 지표와 SHAP 요인 기여도는 만들지 않았고, SHAP 미제공 안내를 표시한다.

## 인터랙션

1. 1개월·3개월·6개월·1년·전체 조회 및 선택일 중심 확대·축소.
2. 차트·행렬 위의 포인터 이동으로 같은 날짜의 상세 정보 확인, 클릭으로 날짜 고정.
3. 오른쪽 날짜 직접 입력, 이전·다음 관측일, 슬라이더와 키보드 이동.
4. 전체 기간 탐색을 펼쳐 드래그로 구간 선택. 시작·종료 범위 입력도 제공.
5. 예측 점수·MSI 표시 선택, 확산도 지표 선택, 분석 근거·원본 경로 확인.
6. 세션 내 기간·날짜·표시 지표 유지, 한국어·영어 전환, 메뉴 Escape 닫기.
